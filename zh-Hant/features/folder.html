以資料夾為主

Butter Edit 直接使用你現有的資料夾。不必複製、不必匯入——開啟資料夾就能開始。

就地開啟資料夾

SD 卡、外接 SSD 或電腦上的任何資料夾都能直接開啟。在 Mac 上，在 Finder 中所做的變更也會立即顯示。

編輯儲存在照片旁的 XMP

評分、排除、顏色標籤與關鍵字寫入其他照片 App 也能讀取的標準 XMP 欄位。原始照片絕不更動。

隨插隨用的磁碟

拔下磁碟後，資料夾會以「未連接」留在側邊欄；重新接上即可繼續，不必重新啟動 App。

縮圖跟著磁碟走

縮圖快取存在照片所在磁碟的隱藏資料夾中，第二次開啟即刻顯示，換一台電腦也一樣。可在設定中選擇大小與位置。

預先製作預覽

在背景為整個資料夾製作螢幕尺寸的預覽，從目前的照片開始，你操作時會自動暫停。

快速挑選

1–5 星、按 X 排除、6–9 設顏色標籤、2–6 張並排比較、堆疊，並可依評分、標籤、AI 精選或標籤篩選。

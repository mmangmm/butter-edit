직접 구입 순서

  1. 결제

    직접 구입 버튼을 클릭하고 결제 화면에서 결제합니다. 한국에서는 원화로, 카드 · 카카오페이 · 네이버페이 · 페이코로 낼 수 있습니다.

  2. 키 받기

    결제가 끝나면 구입 완료 화면에 라이선스 키가 나오고, 같은 키가 이메일로도 옵니다. 메일의 고객 포털 링크로 언제든 다시 볼 수 있습니다. 몇 분이 지나도 메일이 없으면 스팸함을 확인해 주세요.

  3. 설치

    이 웹사이트에서 앱을 내려받아 설치합니다. 키가 없어도 30일 체험은 바로 됩니다.

  4. 활성화

    앱의 설정 → 라이선스에 키를 붙여 넣고 활성화를 클릭합니다. 처음 활성화할 때는 인터넷이 필요합니다.

앱스토어에서 살 때

앱스토어에서 무료로 받고, 앱에서 “30일 무료 체험 시작”을 클릭합니다. 체험 중이든 끝난 뒤든 앱 안에서 잠금 해제를 사면 됩니다. 영수증은 애플이 보냅니다.

구입에 대해 자주 묻는 것

둘 다 사야 하나요?

아니요. 한 곳에서만 사면 됩니다. 맥에서만 쓴다면 앱스토어, 윈도우에서도 쓰려면 직접 구입이 맞습니다.

앱스토어에서 산 것을 윈도우에서도 쓸 수 있나요?

아니요. 앱스토어 구입은 Apple 계정에 묶여 맥 앱스토어 판에서만 풀립니다. 앱스토어 구입과 직접 구입은 서로 옮길 수 없습니다.

컴퓨터를 바꾸면요?

직접 구입: 앱에서 이 컴퓨터를 해제한 뒤 새 컴퓨터에서 활성화합니다. 해제할 수 없으면 이메일로 알려 주세요. 앱스토어: 새 맥에서 ‘구입 복원’을 클릭합니다.

인터넷 없이도 쓸 수 있나요?

직접 구입판은 마지막으로 키를 확인한 뒤 60일까지 인터넷 없이 씁니다. 그 뒤에는 한 번 연결해서 확인합니다.

키를 잃어버렸어요

구입할 때 받은 키 메일을 찾아보세요. 스팸함에 들어가 있을 수도 있습니다. 메일의 고객 포털 링크로도 다시 볼 수 있습니다. 찾을 수 없으면 산 이메일 주소와 함께 알려 주세요.
